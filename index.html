REVENUE NSW · SELECTED WORK

From 5–10 SQL queries to one business search

Auditors used to join records and trace ownership by running roughly 5–10 SQL queries per investigation. I built a dashboard that starts with an ABN or ACN and brings those steps into one workflow.

LangGraph retrieves historical group records. Amazon Neptune exposes ownership paths. Auditors can ask follow-up questions and see, in one click, which businesses joined a group between financial years.

I restricted the dashboard to allow-listed intents and sanitised requests before sending them to Amazon Bedrock. The project targets an 80%+ reduction in investigation effort.
